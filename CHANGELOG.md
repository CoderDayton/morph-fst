# Changelog

## 0.1.0 (unreleased)

First release.

- `Lexer` (the fused lexer), the single entry point: build it with
  `bundled`, `compile`, `compile_with_corpus` or `from_bytes`, then call
  `lex_text` or `lex` with a `Mode`. One `.morph` spec → one compile loop →
  one artifact → one left-to-right scan per word. It gives a full
  morphological analysis, a deterministic WordPiece (LinMaxMatch) fallback,
  or a hybrid output (known affixes around one unknown stem). Internal
  modules are `#[doc(hidden)]`; `generate` is the only other public module.
- Spec language:
  - lexicons with continuation classes and next-morpheme filters;
  - sequential rewrite rules;
  - archiphonemes;
  - left (`FEATURE`) and right (`RFEATURE`) context registers for
    long-distance harmony in both directions;
  - `OPTION harmony underlying` for opaque (non-surface-true) harmony, with
    `@tier=` overrides;
  - lexical exceptions via `@set:` / `@rset:`.
- Exception learning: `INDUCE <features> IN <lexicons>` plus
  `Lexer::compile_with_corpus` learn which roots are exceptions from raw
  text. Hybrid mode infers an unknown stem's exceptions.
- Spec generation: `generate::from_unimorph` / `morph-fst generate` drafts a
  `.morph` spec from UniMorph inflection tables (stems, stem variants,
  shared paradigm classes).
- Zero morphemes: `0 TAG Cont ;` is a tagged paradigm cell with no surface
  (`cat` = cat + SG). Folded away at compile time; `SpecEntry.zeros` /
  `EntryRt.zeros` record the folded tags, and analyses show them as
  empty-surface `Morph`s.
- Stem shapes (`shapes` module, `Morphotactics.shapes`): every ending of a
  known stem, with its class, rule flags and lemma change, shared by at
  least two stems. Hybrid mode builds unknown stems from them, so spelling
  rules and stem changes apply to unseen words. Stems whose lemma has forms
  listed whole (irregulars) lend no shapes.
- Hybrid mode returns every reading ranked by
  `(unknown chars, exceptions, shape support, morphemes)`:
  `WordOutput::Hybrid.all`; `Segment::Unknown.lemma` holds the lemma the
  rules imply.
- Held-out UniMorph lemmas, top reading: English 77.4%, Turkish 84.5%,
  Spanish 68.6% (right features among the readings: 96–99%).
- Bundled English (`data/english.morph`) generated by
  `examples/build_english.rs` from the hand-written grammar
  `tools/english/grammar.morph` and the ESDB word database (MIT-like
  license): 38k stems, each fitted to the class that reproduces its
  inflections, plus 1,521 irregular forms. On all UniMorph English forms:
  hybrid features 74.7%, lemma 92.8%.
- `Lexer::lex_text_par` (same output as `lex_text`, spread over threads) and
  a per-text word cache; `Lexer::from_unimorph` and CLI `--unimorph` build a
  lexer from UniMorph tables with no spec to write.
- Everyday API: `Lexer::analyze` / `analyze_text` return `Word` (`Kind`,
  `Part`s with text, lemma, tag), guessing unknown words by default
  (`Lexer::mode` to change); `Lexer::save` / `load`; `Lexer::builder()`
  (`LexerBuilder`) combines UniMorph tables, a word list, a spec and a
  corpus; CLI `morph-fst new <code>` downloads a UniMorph table and builds
  a lexer. The precise layer (`lex`, `lex_text`, `lex_text_par`,
  `from_unimorph`, `from_wordlist`) is hidden from the docs but still
  works. The internal `analyze(word, cap)` is now `all_analyses`.
- Unknown stems take their class's lemma ending: the empty stem ending is a
  shape too, so `blorf` + `ować` reads as lemma `blorfować` however the stem
  ends. A whole form of another part of speech (`abonując`, tag `V.CVB`) no
  longer marks its lemma irregular, which had hidden every such verb from
  shape derivation. Artifact format version 6: saved `.mcfu` files must be
  rebuilt. Held-out UniMorph lemma and features, top reading (`cargo run
  --release --example heldout`): Polish 60.5% → 74.2%, Russian 59.4% → 76.2%,
  German 17.9% → 38.9%, Korean 0% → 49.4%, Turkish 87.9% → 90.7%, Spanish
  78.5% → 80.3%, English 78.0% → 78.3%; Hungarian unchanged. English
  treebank lemma accuracy 96.7% → 96.6% (a few short unknown words now read
  as stem + `s`). English `as` joined the closed class.
- Context rules: `PREFER tags [OVER tags] AFTER|BEFORE tags` (`"x"` for a
  lemma). In `analyze_text`, a word takes its first reading that fits its
  neighbour; rules are ordered, never weighted. English declares six
  (and `this`/`that`/`what`/`which` gained pronoun readings). UD EWT test,
  part of speech of the best reading: 81.2% → 86.0%; lemma 96.6% → 96.7%.
- Stem shapes record a change at the start of the stem: a prefix
  (`ge|kauf|t` → `kaufen`), one marked letter (`trángala` → `trangar`) and
  a capital (`torheiten` → `Torheit`). Hybrid mode reads those prefixes on
  unseen stems. The generator merges sub-POS (`V.PTCP`, `V.CVB`, `V.MSDR`)
  into their verb's lexeme, and finds stems behind prefixes.
  `OPTION strip_vowel_marks` drops niqqud and harakat (set by the generator
  when the tables use them), and Hebrew final letters match their medial
  forms. Artifact format version 7: saved `.mcfu` files must be rebuilt.
  Held-out UniMorph lemma and features, top reading: German 38.9% → 63.4%,
  Korean 49.4% → 77.9%, Hebrew 34.9% → 52.5%, Arabic 0.5% → 19.8%, Spanish
  80.3% → 84.9%, Russian 76.2% → 81.0%, Polish 74.2% → 77.1%, English
  78.3% → 79.1%; Turkish and Hungarian unchanged.
- `Lexer::terms`: search keys (one lemma per word; numbers, emails, URLs and
  abbreviations whole; punctuation, symbols and clitics dropped), plus the
  `search` example. Form conflation F1 on UD EWT: 80.4% against Porter2's 61.2%.
- `Kind::Name`: a capitalized unknown word in mid-sentence stays whole (tag
  `NAME`). Readings now rank a productive stem + inflection above an
  open-class entry that is itself the inflected spelling (`go`+`ing` over
  `going<N>`); UD EWT lemma accuracy 96.1% → 96.7%. The CLI `tokenize`
  command now guesses by default (`--mode strict` for the old behavior).
- `Word::lemma`: the whole word's dictionary form from its best reading
  (inflection dropped, derivation kept). `Word` readings no longer repeat.
  English closed-class lemmas fixed (`me` → `i`, `them` → `they`, `an` → `a`,
  `ca`/`wo` → `can`/`will`). On UD EWT, lemma accuracy went 92.3% → 96.1%.
  `OPTION derivation TAG,…` lets a grammar say which tags are derivation
  (a tag also covers `TAG:sub`); the artifact format is now version 5, so
  saved `.mcfu` files must be rebuilt.
- `tokenize`, `Token`, `Class`, `Word::span`, `Kind::Literal`: a lossless
  tokenizer (URLs, emails, numbers, initialisms, English clitics, symbols,
  punctuation runs). `analyze_text` and the CLI `tokenize` command use it;
  spans point into the original text, and non-words skip the lexicon. The
  old `lex_text*` layer keeps its simple splitter.
- `discover::from_wordlist`, `Lexer::from_wordlist` and CLI `--wordlist`:
  paradigm discovery (stems, productive suffixes, shared classes) from a
  bare word list, for languages with no tables. Hybrid then borrows the
  discovered endings for unseen stems. Stacked endings are split into
  their productive pieces and chain through a shared tail (Turkish
  stem-boundary accuracy 40% → 52%; English unchanged at 77%). Vowel-harmony
  variants (`lar`/`ler`) that never share a stem get one tag.
- Hybrid: shape ranges are cached per word, and readings that differ only
  in the unknown stem's guessed class or exceptions are kept as distinct
  readings.
- Bundled demo specs: Turkish, Spanish, French, Korean, Igbo.
- Validated binary artifacts (`to_bytes` / `from_bytes`, format version 4).
- Feature `cli`: the `morph-fst` command-line tool.
- Minimum supported Rust version: 1.82.
