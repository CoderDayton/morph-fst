# Changelog

## 0.1.0 (unreleased)

First release.

- `Lexer` (the fused lexer), the single entry point: build it with
  `bundled`, `compile`, `compile_with_corpus` or `from_bytes`, then call
  `lex_text` or `lex` with a `Mode`. One `.morph` spec → one compile loop →
  one artifact → one left-to-right scan per word. It gives a full
  morphological analysis, a deterministic WordPiece (LinMaxMatch) fallback,
  or a hybrid output (known affixes around one unknown stem). Internal
  modules are `#[doc(hidden)]`; `generate` is the only other public module.
- Spec language:
  - lexicons with continuation classes and next-morpheme filters;
  - sequential rewrite rules;
  - archiphonemes;
  - left (`FEATURE`) and right (`RFEATURE`) context registers for
    long-distance harmony in both directions;
  - `OPTION harmony underlying` for opaque (non-surface-true) harmony, with
    `@tier=` overrides;
  - lexical exceptions via `@set:` / `@rset:`.
- Exception learning: `INDUCE <features> IN <lexicons>` plus
  `Lexer::compile_with_corpus` learn which roots are exceptions from raw
  text. Hybrid mode infers an unknown stem's exceptions.
- Spec generation: `generate::from_unimorph` / `morph-fst generate` drafts a
  `.morph` spec from UniMorph inflection tables (stems, stem variants,
  shared paradigm classes).
- Zero morphemes: `0 TAG Cont ;` is a tagged paradigm cell with no surface
  (`cat` = cat + SG). Folded away at compile time; `SpecEntry.zeros` /
  `EntryRt.zeros` record the folded tags, and analyses show them as
  empty-surface `Morph`s.
- Stem shapes (`shapes` module, `Morphotactics.shapes`): every ending of a
  known stem, with its class, rule flags and lemma change, shared by at
  least two stems. Hybrid mode builds unknown stems from them, so spelling
  rules and stem changes apply to unseen words. Stems whose lemma has forms
  listed whole (irregulars) lend no shapes.
- Hybrid mode returns every reading ranked by
  `(unknown chars, exceptions, shape support, morphemes)`:
  `WordOutput::Hybrid.all`; `Segment::Unknown.lemma` holds the lemma the
  rules imply.
- Held-out UniMorph lemmas, top reading: English 77.4%, Turkish 84.5%,
  Spanish 68.6% (right features among the readings: 96–99%).
- Bundled English (`data/english.morph`) generated by
  `examples/build_english.rs` from the hand-written grammar
  `tools/english/grammar.morph` and the ESDB word database (MIT-like
  license): 38k stems, each fitted to the class that reproduces its
  inflections, plus 1,521 irregular forms. On all UniMorph English forms:
  hybrid features 74.7%, lemma 92.8%.
- Bundled demo specs: Turkish, Spanish, French, Korean, Igbo.
- Validated binary artifacts (`to_bytes` / `from_bytes`, format version 4).
- Feature `cli`: the `morph-fst` command-line tool.
- Minimum supported Rust version: 1.82.
